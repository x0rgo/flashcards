Cómo usar

▾ mostrar
  1. Elige un tema con los botones de arriba, o deja "Todos" para ver todas las tarjetas.
  2. Haz clic en la tarjeta para voltearla y ver la respuesta.
  3. Usa ← → para pasar de tarjeta en tarjeta.
  4. Marca cada tarjeta con ✓ Sé esto o ✗ Repasar para llevar tu progreso.
  5. Usa Mezclar para practicar en orden aleatorio, o Reiniciar para borrar tu progreso.
  6. Atajos de teclado: Espacio voltea · 1 Sé esto · 2 Repasar.
